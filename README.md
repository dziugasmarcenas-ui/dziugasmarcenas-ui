- **AI-assisted development:** I use coding assistants as tools, while checking code behaviour against tests, source documents, and explicit acceptance criteria.

My larger SENTRY document-intelligence system and ATLAS manufacturing simulation remain private. Public demonstrations use independently prepared code and synthetic or public data; they are not copies of confidential customer systems.
